# Shepley Magazine website

The website for Shepley Magazine, the free monthly magazine for every household in Shepley.

- **Live site:** the root of this repository (published with GitHub Pages)
- **Preview:** `/preview/`, used to check changes before they go live

## Where things live
- `data/site.json`: sections, contact details and the weekly diary
- `data/issues.json`: every issue, with its articles and that month's diary
- `data/pages-YYYY-MM.json`: the text of every page of an issue, for search
- `issues/YYYY-MM/`: each issue's PDF and cover images
- `assets/`: the design (styles and script)
